# ANTT: selected official records, 2026-09-08

Three small CSV subsets retain the exact original header and complete record bytes (Windows-1252). The source ordinals, byte ranges, SHA-256 hashes, literal cells and acquisition receipts are in metadata.json. The daily subset contains distinct civil days; the legacy subset includes an explicit zero and N/I billing. These subsets do not represent complete resources or national diversity. EOF in parser tests refers only to each subset.
